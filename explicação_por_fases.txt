Primeira etapa -> Entendimento dos Dados
 
Nesta etapa, foi realizada uma análise inicial da base de dados utilizando a biblioteca Pandas. 
O objetivo foi compreender sua estrutura, identificar as colunas disponíveis,
verificar os tipos de dados, analisar as dimensões do conjunto e obter estatísticas descritivas.
Essas verificações permitem conhecer melhor os dados antes de iniciar a etapa de validação, limpeza e tratamento, contribuindo para uma análise mais confiável.

Segunda etapa -> Limpeza e tratamento

Corrigir tipos de dados, tratar valores ausentes, remover duplicatas quando apropriado e padronizar informações.
com a aplicação do protocolo EPA, para um processo de limpeza mais eficiente.

E -> exploração - (EDA) -> Análise exploratória dos dados
P -> Polimento - Corrigir as inconsistências de formatação e digitação
